# WAF Validation Lab

A controlled cybersecurity lab for validating Web Application Firewall
(WAF) detection and blocking behavior against simulated attack patterns.

## Objectives

- Validate WAF detection behavior
- Simulate common web attack patterns
- Analyze WAF logs
- Correlate attack requests with WAF events
- Perform manual validation of detected attacks
- Document validation results

## Lab Components

- Flask-based vulnerable application
- WAF validation endpoints
- Attack simulation
- WAF log analysis
- Validation reports

## Attack Categories

- Command Injection
- Directory Traversal
- Credential Exposure
- Vulnerability Scanning
- Other web attack patterns

## Disclaimer

This project is intended for authorized security testing,
research, and educational lab environments only.
